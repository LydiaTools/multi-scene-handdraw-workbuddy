## 一句话开始

下载上面的ZIP，解压。把完整文件夹交给WorkBuddy或Codex读取，再输入：

> 做一条“为什么你越劝，别人越不听”的多幕手绘短片，直接输出完整视频。

Agent读取Skill、说明四幕安排、检查环境，再从插画实际渲染，不需要你一帧帧剪。

## 这条短片怎么讲

| 幕 | 观众看到的变化 | 要讲清楚的事 |
| --- | --- | --- |
| 劝说 | 一人靠近，建议气泡逐笔出现 | 越想帮忙，对方为何越抗拒 |
| 抗拒 | 对方护住文件，回应“我自己来” | 有时候，问题在于失去决定权 |
| 倾听 | 先问顾虑，注意力转到日程 | 先听清对方真正担心的事 |
| 合作 | 同看计划，路线和任务逐笔出现 | 从给答案转成一起找办法 |

这是多幕插画与真实逐笔细节的组合，不是连续人物视频模型表演。

## 包里有什么

- Skill规则、四幅本期原创插画、故事与落笔时间表。
- 逐笔后端源码、字幕、已生成的本期旁白与音乐混音。
- 运行入口、依赖清单、输出校验与音乐署名。
- 输出MP4、SRT、场景视频、区域标注和制作回执。

**本次验证：** Windows，Codex制作并验证工程，WorkBuddy Hy4用简短主题实际调用重渲染。1920×1080、60fps、10.7秒、642帧。实跑输出SHA256：`1c93cce067d54cbeca3dd1f04926d8272480e336a17e9a41a5acb607643c8fb2`。

## 使用条件

需要能读写本地文件并执行Python的Agent、Python及清单内依赖、可用中文字体。入口检查依赖，优先复用本机兼容环境；缺项会给出明确提示。本包本地绘制与合成不调用收费API。

这条沟通主题的插画、音轨和时间表已齐备，可直接复现。**换新主题要重新生成匹配的故事、插画和音轨**；由Agent安排，生图和配音能力取决于你的宿主工具。本包不含生图模型、私人声音克隆配置或付费接口。不把现成案例的成功当成任意主题都能无条件完成。
